# Proyecto XVerse - Gestión del Proyecto

##  Introducción
Este documento describe la metodología y las herramientas utilizadas para organizar y gestionar el desarrollo del proyecto XVerse.  
El objetivo es asegurar un trabajo colaborativo, ordenado y con entregas incrementales (TP01 a TP10).

---

## Metodología
- Se utilizó una metodología **ágil (Scrum)** adaptada a trabajos prácticos académicos.  
- El proyecto se dividió en **sprints** correspondientes a cada TP (TP01, TP02, TP03, etc.).  
- Cada sprint tuvo objetivos claros:
  - **TP01:** Lectura de dataset y búsqueda secuencial.
  - **TP02:** Experimentos de rendimiento con distintos tamaños de dataset.
  - **TP03:** Implementación de árbol binario de búsqueda.
  - **TP04 a TP10:** Extensiones futuras con nuevas estructuras y algoritmos.

---

## Historial de commits
- El repositorio refleja un avance incremental:
  - Cada TP se subió en etapas.  
  - Los commits muestran la evolución del código y la documentación.  
  - Se mantuvo un estilo claro en los mensajes de commit (ejemplo: *"Agregado árbol binario en TP03"*).

---

## Conclusión
La gestión del proyecto XVerse se realizó de manera ordenada y colaborativa, aplicando principios de Scrum y utilizando Trello como herramienta de organización.  
Esto permitió cumplir con los objetivos de cada TP y dejar el repositorio documentado y con historial de trabajo transparente.
