# ✳ Proyecto XVerse - TP2

## 📌 Descripción
Este trabajo práctico se centra en realizar **experimentos de rendimiento** con distintos tamaños de dataset de videojuegos.  
El objetivo es comparar la eficiencia de diferentes métodos de búsqueda y estructuras de datos en Python.

Se utilizan datasets de:
- 100 juegos (`juegos_100.json`)
- 1000 juegos (`juegos_1000.json`)
- 10000 juegos (`juegos_10000.json`)
